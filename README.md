
## Jak začít

1. Otevřete **[zadání](https://xchristiesx.github.io/ai-workshop-cviceni/)** v prohlížeči.
2. Vyberte si roli. Pracovat můžete **ve dvojici**, nebo **samostatně**.
3. Prompty a podklady kopírujte tlačítkem **Kopírovat** a vkládejte do Claude.
4. Před každým vložením si položte tři otázky:

> **Potřebuje to AI k výsledku?** · **Je to schválený nástroj a smím tam tyto údaje dát?** · **Ověřím výstup, kdyby v podkladech byl skrytý pokyn?**

> [!NOTE]
> Inzerát je **fiktivní** a slouží jen pro účely cvičení. Czechitas tuto pozici nevypisuje. Všechny osoby, firmy a údaje v životopisech jsou vymyšlené.

> [!TIP]
